# Tutor Platform - Спецификация проекта

## Пользователь

**Основной пользователь:** Учащийся, ищущий квалифицированного репетитора

**Вторичные пользователи:**
- Репетиторы, предоставляющие услуги обучения
- Администраторы, модерирующие качество контента

## Проблема

Сложность поиска квалифицированного репетитора без рекомендаций. Отсутствие единой платформы с информацией о квалификации, опыте и отзывах преподавателей.

## Сущность

**Основная сущность:** Профиль репетитора (Tutor)

## Поля сущности

1. **id** (string) - Уникальный идентификатор
2. **name** (string) - Имя репетитора
3. **description** (string, многострочный) - Описание опыта и специализации
4. **experience** (number) - Стаж работы в годах
5. **rating** (number) - Средняя оценка от 0 до 5
6. **registrationDate** (date) - Дата регистрации
7. **status** (статус/категория) - Статус профиля: active, pending, inactive
8. **isAvailable** (boolean) - Доступен ли репетитор сейчас
9. **subjects** (array) - Список преподаваемых предметов
10. **hourlyRate** (number) - Стоимость часа занятия
11. **reviewCount** (number) - Количество отзывов

## Страницы приложения

### Страница 1: Главная (Dashboard)
- **URL:** `/`
- **Назначение:** Главная страница с общей статистикой платформы
- **Отображаемые данные:** Общее количество репетиторов, средний рейтинг, количество активных профилей, последние добавленные репетиторы
- **Действия пользователя:** Просмотр статистики, переход на другие разделы

### Страница 2: Список репетиторов (Catalog)
- **URL:** `/tutors`
- **Назначение:** Каталог всех репетиторов с поиском и фильтрацией
- **Отображаемые данные:** Список репетиторов в виде карточек (имя, рейтинг, предметы, цена), фильтры по предмету, поле поиска, сортировка
- **Действия пользователя:** Поиск по имени/предмету, фильтрация, сортировка, клик на профиль

### Страница 3: Профиль репетитора (Detail)
- **URL:** `/tutors/:id`
- **Назначение:** Подробная информация о репетиторе
- **Отображаемые данные:** ФИО, стаж, рейтинг, описание, предметы, цена, статус профиля, дата регистрации
- **Действия пользователя:** Просмотр информации, для администратора: одобрение/отклонение профиля

### Страница 4: Создание/редактирование профиля (Form)
- **URL:** `/tutors/create` и `/tutors/:id/edit`
- **Назначение:** Форма для создания нового или редактирования существующего профиля
- **Отображаемые данные:** Поля формы для заполнения всех атрибутов сущности, валидация
- **Действия пользователя:** Заполнение формы, сохранение, отмена

### Страница 5: Статистика (Analytics)
- **URL:** `/analytics`
- **Назначение:** Аналитика и статистика по репетиторам
- **Отображаемые данные:** Количество репетиторов по статусам, средний рейтинг, распределение по предметам, топ-10 по рейтингу, средняя цена
- **Действия пользователя:** Просмотр графиков и таблиц

### Страница 6: Модерация (Admin Panel)
- **URL:** `/moderation`
- **Назначение:** Управление профилями на модерации
- **Отображаемые данные:** Список профилей со статусом pending, кнопки одобрения/отклонения, поле для комментариев
- **Действия пользователя:** Просмотр профиля, одобрение, отклонение с комментарием

## Пользовательские сценарии

### Сценарий 1: Поиск репетитора
1. Учащийся переходит на страницу `/tutors`
2. Вводит "Математика" в поле поиска
3. Выбирает фильтр "минимальный рейтинг 4.5"
4. Видит список отфильтрованных репетиторов
5. Клик на репетитора → переход на профиль

### Сценарий 2: Создание профиля репетитора
1. Репетитор нажимает "Создать профиль"
2. Заполняет форму (имя, описание, опыт, предметы, цена)
3. Нажимает "Сохранить"
4. Профиль создается со статусом "pending"

### Сценарий 3: Одобрение профиля администратором
1. Администратор переходит на `/moderation`
2. Видит список профилей на модерации
3. Выбирает профиль
4. Нажимает "Одобрить"
5. Статус профиля меняется на "active"

### Сценарий 4: Отклонение профиля
1. Администратор видит профиль на модерации
2. Вводит причину отклонения в комментарий
3. Нажимает "Отклонить"
4. Профиль переходит в статус "inactive"

### Сценарий 5: Просмотр статистики
1. Пользователь переходит на `/analytics`
2. Видит общую статистику платформы

## Функции, не входящие в первую версию

1. Система отзывов и рейтинга в реальном времени
2. Email-уведомления пользователям
3. Личный кабинет учащегося с историей
4. Система мессаджинга между пользователями
5. Система сертификации репетиторов
